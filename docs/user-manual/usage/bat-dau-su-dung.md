# Bắt đầu sử dụng (5 phút)

Dành cho người chỉ muốn đọc / tải truyện, không cần biết code.

## 1. Mở app

- **Dùng web:** mở link web của bạn (ví dụ Render) bằng Chrome.
  Lần đầu Chrome hỏi cài đặt thì bấm **Install** để có icon ngoài màn hình, lần sau mở như app, không cần mạng vẫn đọc được truyện đã tải.
- **Dùng file .exe trên máy:** giải nén file `.zip` tải về, chạy file `hakuneko.exe`.
  Nếu mở lên chớp 1 cái rồi tắt, tải lại bản mới nhất là hết.

## 2. Chuyển sang Tiếng Việt

1. Mở app, bấm nút **Cài đặt** (hình bánh răng).
2. Mục **Language / Ngôn ngữ** → chọn **🇻🇳 Tiếng Việt (VN)**.
3. App tự nhớ, lần sau mở lên vẫn là Tiếng Việt.

> Nếu không thấy Tiếng Việt: tắt app mở lại, hoặc bấm `Ctrl + Shift + R` để tải lại.

## 3. Tìm truyện để đọc

1. Ở cột trái bấm **Media List**.
2. Chọn 1 website (ví dụ MangaDex).
   Lần đầu nó tải danh sách hơi lâu, đợi 1 chút.
3. Gõ tên truyện vào ô **Search** → bấm vào truyện → hiện danh sách chương.

## 4. Đọc truyện

1. Bấm vào 1 chương → trình đọc mở ra.
2. Kéo chuột / lăn chuột để đọc.
   - Truyện Nhật: để chế độ **Phân trang**
   - Truyện Hàn / màu dài: để chế độ **Dải dài**
3. Bấm mũi tên qua lại để chuyển chương.

## 5. Lưu truyện để đọc sau (Bookmark)

- Trong trang truyện, bấm nút **Thêm vào bookmark** (hình ngôi sao).
- Muốn xem lại: cột trái bấm **Bookmarks**.
- Muốn sao lưu: Menu → **Xuất Bookmark** ra file, khi đổi máy thì **Nhập Bookmark** lại.

## 6. Tải về máy để đọc offline

1. Trong danh sách chương, bấm nút **Tải** ở chương muốn tải.
2. Mở **Downloads** để xem tiến độ: Đang chờ → Đang tải → Hoàn tất.
3. Lần đầu app hỏi **Thư mục lưu**: chọn 1 thư mục, bấm **Cho phép**.
4. File tải về nằm trong thư mục đó, không cần mạng vẫn mở đọc được.

## 7. Dịch sang Tiếng Việt

### Dịch tên truyện / giao diện

1. Vào **Cài đặt → Dịch AI**.
2. Chọn **Google** (miễn phí, không cần key) hoặc **OpenAI / Gemini** (hay hơn, cần nhập key).
3. **Ngôn ngữ đích:** để `vi`.
4. **Tự động dịch:** để TẮT cho đỡ tốn, khi nào cần thì bấm nút Dịch.

### Dịch chữ trong ảnh

1. Vào **Cài đặt → OCR** → chọn **Gemini Vision** hoặc **OpenAI Vision** → nhập key của bạn.
   Chưa có key thì chọn **Google** cũng được.
2. Mở 1 trang truyện, bấm nút **Dịch ảnh** ở góc phải dưới ảnh.
3. Đợi vài giây, chữ nước ngoài sẽ hiện bong bóng trắng đè lên bằng Tiếng Việt.

> Chỉ dịch khi bạn bấm nút, không tự trừ tiền key.

## 8. Đồng bộ qua máy khác (không bắt buộc)

Bỏ qua cũng được. Nếu muốn bookmark giống nhau trên 2 máy:

1. **Cài đặt → Đồng bộ** → chọn **GitHub Gist**.
2. Nhập **Token GitHub** (tạo 1 lần trên github.com, tick quyền `gist`).
3. Bật **Tự động đồng bộ**. Xong.

## 9. Gặp lỗi thì làm gì?

| Thấy gì | Làm gì |
|---|---|
| Mở web báo không an toàn | Bấm **Advanced → Tiếp tục** (do chứng chỉ test, không sao) |
| Trắng trang / lỗi đỏ | Bấm `Ctrl + Shift + R` tải lại |
| Không tải được | Đổi website khác, nhiều web chặn tải |
| Bấm Dịch ảnh báo "Chọn OCR trước" | Vào Cài đặt → OCR chọn provider trước |
| App exe không mở | Tải bản mới nhất trong mục Actions → Build EXE |

Xong. Chỉ cần nhớ 3 chỗ: **Media List để tìm**, **Downloads để tải**, **Cài đặt để đổi Tiếng Việt / Dịch**.
